# Docs for humans, slice 5: SPEC-FORMAT split + HARNESS → CONCEPTS + ABLATION trim + BASELINE → history — Test Contract

> The traceability matrix: every R-id in the `.spec.md` maps to a concrete, executable test, and
> every row names the mutant that kills it. The Reviewer fails the feature if any R-id lacks a
> passing test, or if a named mutant survives that is not a listed known limit.
>
> **Suite.** The slice-1 suite `tests/test_docs_for_humans.sh` (DH) gains the rows below under a
> `# ---- E39-F05` comment; new row functions are named `F05_R<n>_<slug>` (the `R<n>` is this
> spec's R-id); the dispatch-completeness sweep already matches them. The house helpers are
> reused, never duplicated: `slice`, `unfenced`, `folded`, `mermaid_blocks`, `has_heading`,
> `nlines`, `link_targets`, `broken_links`, `mirror`, `registry_each`, `index_rows`,
> `section_diagram`, `shape_problems`, `diagram_problems`, `changelog_problem`. Rows that mutate a
> doc copy it under `$T` first and never touch `$ROOT`; the suite never reads `VERSION` as a
> literal and never git-diffs a DO-NOT-TOUCH file against `main`; no row keeps a byte copy of base
> text (a heredoc copy of the grammar would be a third place the contract is compared — the defect
> class this spec names), so verbatim-ness is proved by Reviewer `diff`s against the base. Exit codes
> are asserted as `rc -eq N`. Installer behaviour (R11 shipping) lives in `tests/test_install.sh`;
> the frozen-oracle regression (R10) lives in `tests/test_codex_native.sh`; the move proof (R1's
> `docs-move-check.sh` clause), the verbatim bodies (R1, R2, R3, R8), the regenerated-glue proof
> (R10's `--self`) and the path-only diff (R9) are Reviewer behavioural checks because a permanent
> suite must not diff against `main` or run the installer in self mode.
>
> **Mutants.** Each row names the smallest edit that must turn it RED. The Reviewer's mutation
> campaign applies each one in isolation on a copy (`cp` / `mv …mutbak` discipline from
> `agents/reviewer.md`), confirms the mutation applied (`grep` the planted text first), and
> restores between mutations. A path written `<agents>/…` or `<history>/…` below is a link target
> relative to `docs/agents/` or `docs/history/`, not a repository path.
